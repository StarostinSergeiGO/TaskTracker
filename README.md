# TaskTracker

## Описание

TaskTracker — консольное приложение для хранения и управления задачами. Проект написан на C# с использованием .NET 8. Приложение позволяет создавать, просматривать и управлять списком задач.

## Используемые технологии

- C#
- .NET 8
- Git

## Требования

Для разработки и запуска проекта требуется .NET 8 SDK.

## Запуск

1. Установить .NET 8 SDK.
2. Открыть терминал в корневом каталоге проекта.
3. Перейти в каталог проекта:
   cd src/TaskTracker
4. Восстановить зависимости:
   dotnet restore
5. Запустить приложение:
   dotnet run

## Основные возможности

- Просмотр списка задач
- Добавление задач
- Удаление задач
- Хранение данных
