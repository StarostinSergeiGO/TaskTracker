# Требования к будущей веб-версии TaskTracker

## 1. Поддерживаемая среда

Веб-интерфейс должен корректно работать как минимум в Яндекс Браузере и Microsoft Edge (Chromium).

## 2. Работа с вкладками

- Пользователь может открыть приложение в нескольких вкладках одновременно.
- Основные данные не должны теряться при случайном закрытии вкладки.
- Интерфейс не должен зависеть от особенностей группировки вкладок конкретного браузера.

## 3. Всплывающие окна (Pop-up)

- Критические функции приложения не должны работать только через автоматически открываемые окна.
- Браузер может заблокировать pop-up — необходимо предусмотреть альтернативный способ.

## 4. Cookies

- Использовать cookies только там, где они действительно необходимы.
- Корректно обрабатывать завершение или потерю пользовательской сессии.
- Не делать основные функции зависимыми от сторонних cookies.

## 5. Авторизация

- Форма входа должна быть совместима со стандартными менеджерами паролей браузеров.
- Поля логина и пароля должны быть стандартными для корректного автозаполнения.
- Кнопка «Запомнить меня» должна работать через безопасные механизмы.

## 6. Разрешения браузера

- Приложение не должно запрашивать камеру, микрофон или геолокацию без необходимости.
- Отказ от необязательного разрешения (например, уведомлений) не должен блокировать основную функциональность.

## 7. Общая совместимость

- Веб-версия должна корректно работать в Firefox и Chromium-браузерах.
- Приватный режим должен поддерживаться.
- Интерфейс должен быть адаптивным.
