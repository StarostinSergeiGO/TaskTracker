# Руководство пользователя TaskTracker

## 1. Назначение программы

TaskTracker — консольное приложение для хранения и управления задачами.

## 2. Запуск

1. Установите .NET 8 SDK.
2. Откройте терминал в каталоге src/TaskTracker.
3. Выполните: dotnet run

## 3. Основные возможности

- Просмотр списка задач
- Добавление новой задачи
- Удаление задачи
- Сохранение данных

## 4. Порядок работы

1. Запустите приложение.
2. Следуйте инструкциям в консоли.
3. Выберите нужное действие.

## 5. Ограничения

Приложение является учебным и работает в консольном режиме.
